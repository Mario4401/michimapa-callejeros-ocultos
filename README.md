# MichiMapa: Callejeros Ocultos

Juego PWA táctil: explora un barrio de 16 pantallas y encuentra 24 gatos semicamusflados. Incluye tres niveles de dificultad, tres vidas y partidas de 2 minutos y 30 segundos.

- Nivel 1: encuentra los gatos en cualquier orden.
- Nivel 2: encuentra los gatos numerados del 1 al 24.
- Nivel 3: completa cuatro grupos de seis colores; el primer gato de cada grupo decide el siguiente color.

## Jugar en local

Sirve la carpeta con cualquier servidor HTTP, por ejemplo `npx serve .`, y abre la URL indicada. El juego también admite ratón.

## Publicación

El proyecto es estático y está preparado para GitHub Pages. En *Settings → Pages*, selecciona *Deploy from a branch*, rama `main` y carpeta raíz `/`.
